## Addressing the aircraft-coverage deadspots

That’s a real limitation: if no aircraft provide readings over a cell, AirGuard should show **UNKNOWN**, not infer that conditions are fine from nearby cells. ADS-B is useful broad-area evidence, but it is not a substitute for local measurements where the drones operate.

A practical additional source is **telemetry from the unit’s own drones**. With operator authorization, ingest the flight controller’s GNSS health data and event logs—for example, fix status, reported accuracy, satellite count, GPS glitches, and discrepancies between independent navigation sources when available. MAVLink defines standard GPS telemetry messages, though the exact fields available depend on the aircraft and autopilot ([MAVLink common messages](https://mavlink.io/en/messages/common.html)).

**Caution:** if GNSS is being spoofed, the drone’s reported position may itself be wrong. Don’t treat that coordinate alone as proof of which cell was affected. Pair the telemetry with independent position evidence where available, or with **fixed GNSS monitoring receivers** near the operating area. Such local receivers can observe signal degradation even when aircraft aren’t overhead; ESA’s GIDAS project describes continuous monitoring and says that multiple stations can support interference localization ([ESA NAVISP: GIDAS](https://navisp.esa.int/project/008-gidas-gnss-interference-analysis-system)).

As a supplementary, broader signal, EASA publishes recently affected flight-information regions—but that is **regional context**, not a real-time, cell-level sensor feed ([EASA GNSS interference information](https://www.easa.europa.eu/en/domains/air-operations/global-navigation-satellite-system-outages-and-alterations)). A SESAR monitoring solution describes real-time area/route status and API/SWIM access, but it is listed as ongoing and has no public datapack, so don’t present it as a ready-to-connect free feed ([SESAR GNSS monitoring](https://www.sesarju.eu/sesar-solutions/real-time-gnss-monitoring-and-interference)).
